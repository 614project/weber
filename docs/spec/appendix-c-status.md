## C.1 구현 상태

현재 컴파일러: **1.0.0**. "구현됨" 절의 예제는 `tests/spec.test.ts` 가 실제로 변환해서 확인합니다.

## C.2 1.0 과 달라지는 점

예정된 기능 가운데 일부는 **1.0 에서 유효했던 코드의 출력을 바꿉니다.** 대부분은 1.0 의 출력이 무효하거나 뜻과 달랐던 경우입니다.

| 코드 | 1.0 의 출력 | 바뀐 출력 | 절 |
| --- | --- | --- | --- |
| `font-size 16` | `font-size: 16` (무효한 CSS) | `font-size: 16px` | [6.2](06-css.md#62-단위-추론) |
| 문서 | viewport 없음 | viewport 메타, (h1 이 있으면) title 추가 | [8.5](08-document.md#85-기본으로-채우는-것) |
| `disabled no` | `disabled="no"` (켜짐) | 속성 없음 (꺼짐) | [5.3](05-attributes.md#53-불리언-속성) |
| `class=box` | `class="=box"` | `class="box"` | [5.2](05-attributes.md#52-등호로-쓰기) |
| `div:` 다음 줄에 깊은 들여쓰기 | 빈 `div` 와 형제들 | 그 줄들을 담은 `div` | [2.9](02-syntax.md#29-들여쓰기-블록) |
| `p > b` | 텍스트 `> b` 를 가진 `p` | `p` 안의 `b` | [2.12](02-syntax.md#212-한-줄-중첩) |
| `li*3` | 텍스트 `*3` 을 가진 `li` | `li` 3개 | [2.13](02-syntax.md#213-반복) |
| 텍스트 안의 `$이름` | 글자 그대로 | 변수의 내용 (정의되지 않았으면 그대로 두고 경고) | [9.2](09-reuse.md#92-끼워넣기) |
| `ul { .item }` | `div.item` | `li.item` | [4.8](04-content.md#48-문맥에-따른-태그-생략) |
| `section { li: "a" }` | `section` 안의 `li` | `ul` 로 감싼 `li` | [4.9](04-content.md#49-자동으로-감싸기) |
| 문서 최상위의 `--accent` | `<html>` 의 인라인 스타일 | `:root` 규칙 | [6.4](06-css.md#64-css-변수) |
| 본문 안의 `title { }`, `meta` | 본문에 그대로 | `<head>` 로 옮김 | [8.4](08-document.md#84-끌어올리기) |
| `size 48` | `size: 48` (무효한 CSS) | `width: 48px; height: 48px` | [6.5](06-css.md#65-별칭) |
| `hover { … }` | 알 수 없는 요소 `<hover>` | `:hover` 규칙 | [6.8](06-css.md#68-상태-블록) |
| `img cat.png "고양이"` | `src='cat.png "고양이"'` | `src="cat.png" alt="고양이"` | [4.3](04-content.md#43-요소-값의-인자) |

다음은 1.0 에서 **오류였던** 표기라 기존 코드에 영향이 없습니다: 텍스트 줄(`|`), 목록 항목(`-`), 원본 HTML(`<`), 링크 화살표(`->`), 변수 선언(`$`), 지시문(`@include` 등), 파일 끝의 닫히지 않은 블록, 조각 최상위의 `lang` 같은 속성.

이 변화들은 한 번에 묶어 **weber 2.0** 으로 내기를 권합니다. 오류였던 표기만 추가하는 기능은 1.x 에서 먼저 낼 수 있습니다.

## C.3 구현 순서 제안

쓰는 사람에게 돌아가는 효과가 크고 위험이 작은 것부터입니다.

1. **CSS 설탕** — 단위 추론, `!` 줄임, CSS 변수, 별칭, layout, 상태 이름, 반응형 별칭. weber 로 스타일을 쓰는 경험이 가장 크게 좋아집니다.
2. **요소 설탕** — `=` 표기, 불리언 확장, 요소 값의 인자, 링크 화살표, 텍스트 줄, 목록·표 설탕, 태그 생략, 자동 감싸기, 원본 HTML.
3. **문법 확장** — 들여쓰기 블록, 한 줄 중첩, 반복, 닫히지 않은 블록 자동 닫기, CSS 값 이어 쓰기, 출력 주석.
4. **문서와 스크립트** — viewport·title 채우기, 끌어올리기, head 설탕 추가, `@이벤트`와 수식어, `module`.
5. **재사용과 설정** — 변수와 끼워넣기, 컴포넌트와 슬롯, `@include`·`@use`, `@each`·`@if`, `@set`, 엄격 모드, 경고 코드, `--explain`.
6. **그 밖** — 마크다운, 자동 접두사.

각 단계를 마칠 때마다 플레이그라운드의 예제와 소개 사이트를 새 문법으로 바꿔, 사이트가 언제나 최신 weber 를 보여 주게 합니다.
