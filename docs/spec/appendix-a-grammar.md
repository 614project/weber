# 부록 A. 문법 요약

[← 11. 진단과 출력](11-diagnostics-output.md) · [목차](../README.md) · 다음: [부록 B. 참조 표 →](appendix-b-reference.md)

본문의 규칙을 짧은 표기로 모았습니다. 본문과 다르면 본문이 우선합니다. `(예정)` 이 붙은 줄은 아직 구현되지 않은 문법입니다.

## A.1 표기

```text
A B        A 다음에 B
A | B      A 또는 B
[ A ]      A 가 있어도 없어도 됨
{ A }      A 가 0번 이상
"x"        글자 x 그대로
```

## A.2 weber 문장

```text
파일        = { 사이 } { 문장 { 사이 } } ;
사이        = 공백 | 줄바꿈 | ";" | 주석 ;

문장        = 키문장
            | 텍스트
            | 텍스트줄                                  (예정)
            | 목록항목                                  (예정)
            | 원본HTML                                  (예정)
            | 출력주석                                  (예정)
            | 요소규칙
            | 지시문                                    (일부 예정)
            | 변수선언                                  (예정)
            | 링크 ;                                    (예정)

키문장      = 마디 { " > " 마디 }                        ( > 는 예정)
              [ 나눔 값 ] [ 블록 ] ;
마디        = 이름 [ 축약 ] [ 반복 ] [ 부르기 ]           (반복, 부르기는 예정)
            | 축약 [ 반복 ] ;
이름        = [ "-" [ "-" ] ] 영문자_ { 영문자 | 숫자 | "_" | "-" } ;
축약        = { "." 이름 | "#" 이름 | "[" 속성쌍 { 공백 속성쌍 } "]" } ;  (여러 쌍은 예정)
속성쌍      = 속성이름 [ "=" ( 문자열 | 낱말 ) ] ;
반복        = "*" 정수 ;                                 (예정)
부르기      = "(" [ 값 { "," 값 } ] ")" ;                 (예정, 컴포넌트)

나눔        = 공백 | ":" | "=" ;                         ( = 는 예정, 언제나 속성)
값          = 줄 끝, 괄호 밖의 ";" "}" "{", 공백 뒤의 "//" 전까지의 글자 ;
블록        = "{" { 사이 | 문장 } "}"
            | ":" 줄바꿈 들여쓴줄 { 들여쓴줄 } ;          (들여쓰기는 예정)

텍스트      = 문자열 ;
문자열      = '"' { 글자 } '"' | "'" { 글자 } "'" | "`" { 글자 | 줄바꿈 } "`" ;
텍스트줄    = "|" [ " " ] { 줄 끝까지의 글자 } ;
목록항목    = ( "-" | "*" | 정수 ( "." | ")" ) ) 공백 [ 값 ] [ 블록 ] ;
원본HTML    = "<" { 줄 끝까지의 글자 } ;
출력주석    = "<!--" { 글자 } "-->" ;
링크        = ( 텍스트 | 키문장 ) ( "->" | "→" ) 주소 [ 블록 ] ;

요소규칙    = ( ":" | "&" | "@" ) 선택자 CSS블록 ;
변수선언    = "$" 이름 [ ":" | "=" ] 값 ;
지시문      = "@include" 문자열
            | "@use" 문자열
            | "@set" 이름 값
            | "@component" 이름 [ "(" 매개변수 { "," 매개변수 } ")" ] 블록
            | "@slot" [ 이름 ] [ 블록 ]
            | "@each" 변수 [ "," 변수 ] "in" 목록 블록
            | "@if" 조건 블록 { "@else if" 조건 블록 } [ "@else" 블록 ] ;
매개변수    = 이름 [ "=" 값 ] ;
목록        = "[" [ 값 { "," 값 } ] "]" | 정수 ".." 정수 | 변수 | "@json" 문자열 ;
```

## A.3 코드 블록

`script`, `module`, `on…`, `@이벤트` 의 블록은 자바스크립트로 읽어, 문자열·템플릿 리터럴·정규식·주석 밖에서 짝이 맞는 `}` 까지를 내용으로 삼습니다. 한 줄 값은 괄호가 모두 닫힌 줄 끝(또는 짝 없는 `}`, `//` 주석)까지입니다.

## A.4 CSS 블록

`style`, `css`, 요소 규칙(`:hover { }` 등)의 블록에 씁니다.

```text
CSS블록     = "{" { CSS사이 | CSS항목 } "}" ;
CSS사이     = 공백 | 줄바꿈 | ";" | 주석 ;
CSS항목     = 선언 | 중첩규칙 | at문 | 묶음 ;            (묶음은 예정)
선언        = CSS이름 ( ":" | 공백 ) CSS값 [ "!" ] ;     ( ! 는 예정)
중첩규칙    = 선택자 CSS블록 ;
at문        = "@" 이름 { 글자 } ";" ;                    (@import 등)
묶음        = 이름 "-" CSS블록 ;
```

- 선언과 선택자는 줄 끝, `;`, `{`, `}` 에서 끝납니다. 다음 경우에는 줄을 넘겨 이어집니다: 괄호가 열려 있을 때, 줄이 `,` 로 끝날 때, 다음 줄이 `{` 나 따옴표로 시작할 때.
- `{` 앞에서 끝나면 중첩 규칙, 그 밖에는 선언입니다. `@` 로 시작하고 `{` 없이 끝나면 at문입니다.
