# 2. 기본 문법

[← 1. 개요](01-overview.md) · [목차](../README.md) · 다음: [3. 판별 →](03-classification.md)

이 장은 weber 코드가 어떻게 문장과 블록으로 나뉘는지를 정합니다. 각 문장이 무엇이 되는지는 [3장](03-classification.md)에서 다룹니다.

## 2.1 소스 텍스트

> 상태: 구현됨

- 소스는 UTF-8 텍스트입니다. 맨 앞의 BOM 은 무시합니다.
- 줄바꿈은 `\n`, `\r\n`, `\r` 어느 것이든 되며, 모두 `\n` 으로 통일해서 읽습니다.
- 파일 확장자는 `.weber` 를 씁니다.

## 2.2 주석

> 상태: 구현됨

| 표기 | 뜻 |
| --- | --- |
| `// ...` | 줄 끝까지 주석. 문장 맨 앞이나 **공백 뒤**에서만 주석이 됩니다 |
| `/* ... */` | 여러 줄 주석. 값 안에서는 **공백 뒤**에서만 주석이 됩니다 |

"공백 뒤" 조건 덕분에 URL 의 `//` 나 `image/*` 의 `/*` 는 주석이 되지 않습니다.

```weber
// 한 줄 주석
/* 여러 줄
   주석 */
nav {
    a: "홈" { href https://example.com }   // URL 의 // 는 주석이 아닙니다
    input { accept image/* }              // image/* 도 그대로입니다
}
```

```html
<nav><a href="https://example.com">홈</a><input accept="image/*"></nav>
```

`//` 로 시작하는 값(프로토콜 생략 URL 등)은 따옴표로 감싸야 합니다: `src "//cdn.example.com/a.js"`.

### 2.2.1 출력에 남는 주석

> 상태: 예정

문장 자리에 쓴 `<!-- ... -->` 는 지우지 않고 HTML 주석으로 출력합니다. 저작권 표시 같은 것을 결과물에 남길 때 씁니다.

```weber 예정
<!-- © 614project -->
p: "본문"
```

```html
<!-- © 614project -->
<p>본문</p>
```

## 2.3 문장의 종류

> 상태: 표의 각 줄에 적혀 있습니다

문장의 종류는 첫 글자로 정해집니다.

| 첫 글자 | 문장 | 예 | 상태 | 자세히 |
| --- | --- | --- | --- | --- |
| 이름 | 키 문장 | `p: "안녕"`, `color red`, `div { }` | 구현됨 | 이 장, [3장](03-classification.md) |
| `.` `#` `[` | 태그를 생략한 요소 | `.card { }` | 구현됨 | [2.11](#211-선택자-축약) |
| `"` `'` `` ` `` | 텍스트 | `"안녕하세요"` | 구현됨 | [2.14](#214-문자열) |
| `:` `&` | 요소 안의 CSS 규칙 | `:hover { }` | 구현됨 | [6.10](06-css.md#610-요소-안의-css-규칙) |
| `@` | 지시문, 이벤트, CSS at-규칙 | `@media … { }`, `@click { }`, `@include "a.weber"` | 일부 구현됨 | [3.4](03-classification.md#34-지시문과-at-문장) |
| `$` | 변수 선언 | `$brand #6c4cf1` | 예정 | [9.1](09-reuse.md#91-변수) |
| `\|` | 텍스트 줄 | `\| 따옴표 없는 "텍스트"` | 예정 | [4.5](04-content.md#45-텍스트-줄) |
| `-` `*` 와 공백, `1.` | 목록 항목 | `- 사과` | 예정 | [4.6](04-content.md#46-목록-설탕) |
| `<` | 원본 HTML | `<iframe ...></iframe>` | 예정 | [4.10](04-content.md#410-원본-html) |

## 2.4 키

> 상태: 구현됨

키는 문장 맨 앞의 이름입니다.

- 영문자 또는 `_` 로 시작하고, 영문자·숫자·`_`·`-` 로 이어집니다: `h1`, `font-size`, `data-id`, `my-card`.
- CSS 사용자 정의 속성과 벤더 접두사를 위해 `--` 나 `-` 로 시작할 수도 있습니다: `--accent`, `-webkit-line-clamp`.
- HTML 의 요소와 속성 이름은 대소문자를 구분하지 않습니다. 출력할 때 요소 이름은 소문자로 씁니다.
- SVG 의 이름은 표준 표기로 고쳐 씁니다: `lineargradient` → `linearGradient`, `viewbox` → `viewBox`.

## 2.5 키와 값 사이

> 상태: 구현됨 (`=` 표기는 예정)

키와 값 사이에는 공백이나 쌍점(`:`)을 씁니다. 두 표기는 완전히 같습니다. 쌍점 뒤의 공백은 있어도 없어도 됩니다.

```weber
p hello
p: hello
p:hello
```

```html
<p>hello</p>
<p>hello</p>
<p>hello</p>
```

등호(`=`)도 쓸 수 있습니다. HTML 속성 표기(`class="box"`)를 그대로 쓸 수 있게 하려는 것이며, **`=` 로 쓴 문장은 판별 없이 언제나 HTML 속성**이 됩니다. [5.2](05-attributes.md#52-등호로-쓰기)를 보세요.

## 2.6 값이 끝나는 곳

> 상태: 구현됨

값은 다음 중 가장 먼저 나오는 곳에서 끝납니다.

- 줄 끝
- 괄호 밖의 `;`
- 괄호 밖의 `}` (블록의 끝)
- 괄호 밖의 `{` (블록의 시작. 값과 블록을 함께 쓴 것)
- 공백 뒤의 `//` (주석)

값 안의 따옴표 문자열과 괄호 `( )` `[ ]` 안은 건너뜁니다. 그래서 `url(data:image/png;base64,…)` 의 `;` 는 값을 끝내지 않습니다.

```weber
p { "가격: "; b: 5000; "원" }
div { background url(data:image/png;base64,AAA=) }
```

```html
<p>가격: <b>5000</b>원</p>
<div style="background: url(data:image/png;base64,AAA=)"></div>
```

다음 글자가 들어가는 텍스트는 따옴표로 감싸야 합니다: `;`, `{`, `}`, 공백 뒤의 `//`, 그리고 맨 앞의 `"` 와 `'`.

**값 앞뒤의 공백은 지웁니다.** 텍스트에 앞뒤 공백이 필요하면 따옴표로 감쌉니다: `" 원"`.

이벤트(`onclick` 등)와 `script` 의 한 줄 값은 자바스크립트로 읽습니다. 이때는 `;` 도 값에 포함되고 줄 끝까지가 값입니다. [7.1](07-javascript.md#71-on-이벤트)을 보세요.

### 2.6.1 CSS 값 이어 쓰기

> 상태: 예정

CSS 속성의 값은 다음 경우 다음 줄로 이어집니다. 여러 겹의 그림자나 `grid-template-areas` 처럼 긴 값을 나눠 쓰기 위한 것입니다.

- 줄이 `,` 로 끝날 때
- 괄호가 열린 채 줄이 끝날 때
- 다음 줄이 따옴표로 시작할 때

```weber 예정
.card {
    box-shadow 0 1 2 rgb(0 0 0 / 10%),
               0 8 24 rgb(0 0 0 / 10%)
    grid-template-areas "head head"
                        "side main"
}
```

```html
<div class="card" style='box-shadow: 0 1px 2px rgb(0 0 0 / 10%), 0 8px 24px rgb(0 0 0 / 10%); grid-template-areas: "head head" "side main"'></div>
```

CSS 속성이 아닌 키(텍스트 등)의 값은 줄 끝에서 끝납니다. `p: 안녕,` 다음 줄의 문장이 텍스트에 붙지 않도록 하기 위해서입니다.

## 2.7 한 줄에 여러 문장

> 상태: 구현됨

`;` 로 문장을 나눌 수 있습니다. 줄 끝의 `;` 나 빈 문장(`;;`)은 무시합니다. CSS 처럼 `color: red;` 로 써도 되는 것은 이 때문입니다.

```weber
button { "확인"; color white; background black }
```

```html
<button style="color: white; background: black">확인</button>
```

## 2.8 블록

> 상태: 구현됨

블록은 `{ }` 로 문장을 묶습니다. 다음 모양을 모두 쓸 수 있습니다.

```weber
nav { a: "홈" }
nav: { a: "홈" }
a: "홈" { href / }
nav
{
    a: "소개"
}
```

```html
<nav><a>홈</a></nav>
<nav><a>홈</a></nav>
<a href="/">홈</a>
<nav><a>소개</a></nav>
```

- `키 { }` 와 `키: { }` 는 같습니다.
- 값과 블록을 함께 쓸 수 있습니다(`a: "홈" { href / }`). 값은 블록 내용의 맨 앞에 들어갑니다.
- 여는 중괄호는 다음 줄에 써도 됩니다. 문장은 `{` 로 시작할 수 없으므로 헷갈릴 일이 없습니다.

## 2.9 들여쓰기 블록

> 상태: 예정

중괄호 대신 들여쓰기로 블록을 만들 수 있습니다.

```weber 예정
header:
    h1: "weber"
    nav:
        a: "홈" { href / }
        a: "소개" { href /about }
main:
    p: "들여쓰기로도 블록을 만들 수 있습니다."
```

```html
<header>
  <h1>weber</h1>
  <nav><a href="/">홈</a><a href="/about">소개</a></nav>
</header>
<main>
  <p>들여쓰기로도 블록을 만들 수 있습니다.</p>
</main>
```

**규칙**

1. 키(선택자 축약 포함) **바로 뒤에** `:` 를 쓰고 줄을 끝내면, 들여쓰기 블록이 열립니다.
2. 다음 줄부터, 그 키가 있는 줄보다 깊게 들여쓴 줄들이 블록의 내용입니다. 들여쓰기가 같거나 얕은 줄에서 블록이 끝납니다.
3. 빈 줄과 주석만 있는 줄은 들여쓰기를 따지지 않습니다.
4. 들여쓰기는 스페이스든 탭이든 되지만, 한 블록 안에서는 같은 문자로 깊이를 맞춰야 합니다. 깊이를 비교할 수 없게 섞였다면 오류입니다.
5. 값이 있는 문장은 들여쓰기 블록을 열지 않습니다. `p: 다음과 같습니다:` 의 끝 `:` 는 값의 일부입니다.
6. 들여쓰기 블록 안에서 중괄호 블록을 쓸 수 있고, 그 반대도 됩니다.
7. `script:`, `style:`, `onclick:` 처럼 코드를 담는 키도 들여쓰기 블록을 열 수 있습니다. 블록 내용은 공통 들여쓰기를 뺀 원본 코드입니다.

```weber 예정
button:
    "저장"
    onclick:
        const data = collect()
        save(data)
```

```html
<button onclick="const data = collect()
save(data)">저장</button>
```

> 1.0 과의 차이: 지금까지 `div:` 만 쓴 줄은 빈 `div` 였습니다. 다음 줄이 더 깊게 들여쓰여 있으면 이제는 그 줄들을 담는 블록이 됩니다.

## 2.10 닫히지 않은 블록

> 상태: 예정 (1.0 에서는 오류)

파일 끝까지 닫히지 않은 블록은 파일 끝에서 자동으로 닫고 **경고**합니다. 엄격 모드에서는 오류입니다.
짝이 맞지 않는 `}` (열린 블록이 없는데 나온 `}`)는 여전히 오류입니다. 구조가 어긋난 것이므로 고쳐야 합니다.

## 2.11 선택자 축약

> 상태: 구현됨

키 뒤에 CSS 선택자처럼 `.클래스`, `#아이디`, `[속성=값]` 을 붙일 수 있습니다. 키와 축약 사이에 공백을 두지 않습니다.

```weber
a.btn.primary#go[href="/next"][target=_blank]: "다음"
.card { "태그를 생략하면 div 입니다" }
input[type=checkbox][checked]
```

```html
<a id="go" class="btn primary" href="/next" target="_blank">다음</a>
<div class="card">태그를 생략하면 div 입니다</div>
<input type="checkbox" checked>
```

- 선택자 축약이 붙은 키는 언제나 요소입니다.
- `[속성]` 처럼 값이 없으면 불리언 속성입니다.
- 축약의 클래스와 블록 안의 `class` 문장은 합쳐집니다.

### 2.11.1 한 괄호에 여러 속성

> 상태: 예정

괄호 하나에 속성을 공백으로 나눠 여러 개 쓸 수 있습니다.

```weber 예정
input[type=checkbox name=agree checked]
```

```html
<input type="checkbox" name="agree" checked>
```

### 2.11.2 태그 생략

> 상태: 예정 (1.0 에서는 언제나 `div`)

태그를 생략하면 보통 `div` 지만, 부모에 따라 알맞은 태그가 됩니다(`ul` 안에서는 `li` 등). [4.8](04-content.md#48-문맥에-따른-태그-생략)을 보세요.

## 2.12 한 줄 중첩

> 상태: 예정

`>` 로 요소를 한 줄에 중첩할 수 있습니다. Emmet 의 표기와 같습니다.

```weber 예정
nav > ul > li > a: "홈" { href / }
```

```html
<nav>
  <ul>
    <li><a href="/">홈</a></li>
  </ul>
</nav>
```

**규칙**

- `>` 앞뒤에는 공백을 둡니다. 각 마디는 키와 선택자 축약(반복 포함)입니다.
- 값과 블록은 마지막 마디의 것입니다.
- 쌍점 뒤의 `>` 는 값의 일부입니다: `p: > 인용` 은 텍스트 `> 인용` 입니다.
- `>` 뒤가 키 모양이 아니면 중첩이 아닙니다: `p > 5` 는 지금처럼 텍스트 `> 5` 를 가진 `p` 입니다.

## 2.13 반복

> 상태: 예정

키 뒤에 `*N` 을 붙이면 같은 요소를 N 번 만듭니다. 값과 블록 안에서 `$i` 는 1부터 세는 번호입니다.

```weber 예정
ul > li*3: "항목 $i"
```

```html
<ul>
  <li>항목 1</li>
  <li>항목 2</li>
  <li>항목 3</li>
</ul>
```

- N 은 1 이상 1000 이하의 정수입니다.
- 반복은 마디마다 붙일 수 있습니다: `ul*2 > li*3` 은 `li` 를 3개씩 가진 `ul` 2개입니다.
- `$i` 는 가장 가까운 반복의 번호입니다. 바깥 반복의 번호까지 필요하면 [`@each`](09-reuse.md#97-반복)를 씁니다.
- `$i` 는 [9.2 끼워넣기](09-reuse.md#92-끼워넣기) 규칙을 따릅니다.

## 2.14 문자열

> 상태: 구현됨

| 표기 | 뜻 |
| --- | --- |
| `"..."`, `'...'` | 한 줄 문자열 |
| `` `...` `` | 여러 줄 문자열. 내용을 그대로 담습니다 |
| 여는 `` ` `` 바로 뒤에서 줄바꿈 | 블록 문자열. 첫 줄바꿈, 마지막 빈 줄, 공통 들여쓰기를 지웁니다 |

```weber
p: "따옴표 \"안\"의 따옴표"
p: 'it\'s'
p: "\u{1F600} é"
pre {
    `
    블록 문자열은
        공통 들여쓰기를 뺍니다
    `
}
```

```html
<p>따옴표 "안"의 따옴표</p>
<p>it's</p>
<p>😀 é</p>
<pre>블록 문자열은
    공통 들여쓰기를 뺍니다</pre>
```

**이스케이프**

| 표기 | 뜻 |
| --- | --- |
| `\n` `\t` `\r` `\0` | 줄바꿈, 탭, 캐리지 리턴, 널 문자 |
| `\\` `\"` `\'` `` \` `` | 그 글자 자체 |
| `\xHH`, `\uHHHH`, `\u{H…}` | 유니코드 코드 포인트 |
| 줄 끝의 `\` | 줄 이어 쓰기 (줄바꿈을 넣지 않음) |
| `\$` | `$` 글자 자체 ([끼워넣기](09-reuse.md#92-끼워넣기)를 막음, 예정) |

- 따옴표로 시작한 값이 같은 줄에서 닫히지 않으면 오류입니다. 따옴표 없는 텍스트 중간의 `'`(예: `it's`)는 그냥 글자입니다.
- 텍스트 안의 `<`, `>`, `&` 는 출력할 때 자동으로 이스케이프합니다. HTML 을 그대로 넣으려면 [원본 HTML](04-content.md#410-원본-html)을 씁니다.
- 문자열 안의 `$이름`, `${이름}` 은 변수로 바뀝니다. [9.2](09-reuse.md#92-끼워넣기)를 보세요(예정).
